# Quickstart

Welcome to ModusBrain! This guide will have you using versioned, confidence-gated operational skills with AI agents in a few minutes. By the end, you'll understand how to install the CLI, initialize a local brain, and audit actions.

## Before you begin

Make sure you have:
* A terminal or command prompt open
* [Bun](https://bun.sh) (>= 1.3.10) or [Node.js](https://nodejs.org) installed
* A code project or document directory to serve as your brain source context

<Info>
  This guide covers the local terminal CLI. ModusBrain is also available to run as an MCP server with **Claude Desktop**, **Claude Code**, **ChatGPT**, and other developer tools.
</Info>

---

## Step 1: Install ModusBrain

Install the global CLI using your package manager of choice:

```bash
npm install -g @genthropic/modusbrain
# or
bun install -g @genthropic/modusbrain
```

---

## Step 2: Initialize your brain

Initialize your database configuration. This sets up a fast, zero-config embedded PGLite database locally at `~/.modusbrain` (no database server required):

```bash
modusbrain init
modusbrain apply-migrations --yes
modusbrain config set schema_pack gbrain-base-v2
```

---

## Step 3: Compile your first skill

Draft an operational skill from your brain's existing document context. Compiling translates your prose guidelines into a draft version for your agent:

```bash
modusbrain opskill compile "refund handling" --risk-tier low_stakes
modusbrain opskill show refund-handling
```

---

## Step 4: Approve and execute

Draft skills are confidence-gated and cannot be executed by agents until explicitly approved by an owner:

```bash
# Promote the draft version to active status
modusbrain opskill approve refund-handling --by owner@company.com

# Execute the skill with confidence scoring
modusbrain opskill execute refund-handling \
  --task "Process $300 refund for order #1204" \
  --context '{"amount":300}'
```

---

## Step 5: Check the audit trail

Review the secure audit ledger log containing skill slugs, versions, confidence scores, results, and executor IDs:

```bash
modusbrain opskill audit --slug refund-handling --json
```
