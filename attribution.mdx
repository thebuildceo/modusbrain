# Attribution

ModusBrain is built on **[ModusBrain](https://github.com/garrytan/gbrain)**, an open-source knowledge engine by Garry Tan, licensed under the **MIT License**.

## What ModusBrain provides

- Hybrid RAG search and synthesis
- Knowledge graph and entity extraction
- Dream cycle (autonomous freshness)
- MCP server and multi-source brains

## What ModusBrain adds

- Versioned operational skill compilation
- Confidence gating and approval workflows
- Conflict resolution queues
- Agent action audit trails
- Closed feedback loop (corrections → re-compile)
