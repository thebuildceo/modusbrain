# Install

## From source (recommended for now)

```bash
git clone https://github.com/thebuildceo/modusbrain.git
cd modusbrain
bun install --ignore-scripts
bun link
modusbrain --version
```

## From GitHub (global)

```bash
bun install -g github:thebuildceo/modusbrain
```

If postinstall fails on Windows, run:

```bash
bun install -g github:thebuildceo/modusbrain --ignore-scripts
modusbrain init
modusbrain apply-migrations --yes
```

## Build a binary

```bash
bun run build
# Output: bin/modusbrain
```

## Config directory

| Path | Purpose |
| --- | --- |
| `~/.modusbrain` | Default config + brain data (new installs) |
| `~/.modusbrain` | Legacy path — auto-detected if present |

## Environment variables

Prefer `MODUSBRAIN_*` — legacy `MODUSBRAIN_*` still works. See [Environment variables](/env-vars).

## Verify install

```bash
modusbrain doctor
modusbrain opskill list
```
