# Install

## From npm (recommended)

Install globally via npm or Bun:

```bash
npm install -g @genthropic/modusbrain
# or
bun install -g @genthropic/modusbrain
```

## From GitHub / Source

If you want to install directly from the repository or build from source:

```bash
# Global install from GitHub:
bun install -g github:thebuildceo/modusbrain

# Or build and link from source:
git clone https://github.com/thebuildceo/modusbrain.git
cd modusbrain
bun install --ignore-scripts
bun link
```

If postinstall fails on Windows, run:

```bash
npm install -g @genthropic/modusbrain --ignore-scripts
# or
bun install -g @genthropic/modusbrain --ignore-scripts
modusbrain init
modusbrain apply-migrations --yes
```

## Build a binary

```bash
bun run build
# Output: bin/modusbrain
```

## Config directory

| Path | Purpose |
| --- | --- |
| `~/.modusbrain` | Default config + brain data (new installs) |
| `~/.gbrain` | Legacy path — auto-detected if present |

## Environment variables

Prefer `MODUSBRAIN_*` — legacy `GBRAIN_*` still works. See [Environment variables](/env-vars).

## Verify install

```bash
modusbrain doctor
modusbrain opskill list
```
