# Install ModusBrain

ModusBrain runs as a global command-line interface (CLI) built on Bun. You can install it via npm, Bun, or directly from source.

## Before you begin

Make sure you have:
* **Bun** (>= 1.3.10) or **Node.js** (>= 18.0.0) installed on your system.
* A terminal or command prompt open.
* Access to configure an AI API key (such as ZeroEntropy or OpenAI) for search embeddings.

---

## Installation methods

Choose the package manager or installation method that best fits your local workflow:

<Tabs>
  <Tab title="npm (Recommended)">
    Install the global CLI using npm:

    <Tabs>
      <Tab title="macOS, Linux, WSL">
        ```bash
        npm install -g @genthropic/modusbrain
        ```
      </Tab>
      <Tab title="Windows PowerShell">
        Open PowerShell as Administrator and run:
        ```powershell
        npm install -g @genthropic/modusbrain
        ```
      </Tab>
    </Tabs>
  </Tab>

  <Tab title="Bun">
    Install the global CLI using Bun's package manager:

    <Tabs>
      <Tab title="macOS, Linux, WSL">
        ```bash
        bun install -g @genthropic/modusbrain
        ```
      </Tab>
      <Tab title="Windows PowerShell">
        ```powershell
        bun install -g @genthropic/modusbrain
        ```
      </Tab>
    </Tabs>
  </Tab>

  <Tab title="From Source">
    Clone the repository and link it locally for development:

    ```bash
    git clone https://github.com/thebuildceo/modusbrain.git
    cd modusbrain
    bun install --ignore-scripts
    bun link
    ```
  </Tab>
</Tabs>

<Note>
  If the global installation post-install hook fails on Windows, run the installation with the `--ignore-scripts` flag:
  `npm install -g @genthropic/modusbrain --ignore-scripts` (or the equivalent Bun command), then run `modusbrain init` manually.
</Note>

## Post-Installation

### 1. Verification
Ensure the installation succeeded by checking the version and system status:

```bash
modusbrain --version
modusbrain doctor
```

### 2. File and Environment Setup
ModusBrain keeps its configuration and local database files stored in the home directory.

| Path | Purpose |
| :--- | :--- |
| `~/.modusbrain` | Default config, schema caches, and brain data databases (new installs) |
| `~/.gbrain` | Legacy config fallback — auto-detected if existing config is present |

Prefer configuring behavior through environment variables using the preferred `MODUSBRAIN_*` namespace. Legacy `GBRAIN_*` variables are also resolved. See [Environment variables](/env-vars) for details.
